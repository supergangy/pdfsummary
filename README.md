# pdfsummary — 필기한 부분만 모아 주는 PDF 요약본

PDF 책에 **형광펜으로 칠한 부분, 밑줄 그은 부분, 동그라미 친 부분, 손으로 쓴 메모**만 뽑아서
단원별로 깔끔하게 정리해 줍니다. 손글씨는 Claude AI가 읽어서 글로 바꾸고, 애매한 글씨는 **원본 이미지를 같이** 넣어 줍니다.

```bash
pdfsummary 생명과학.pdf
```

```
📖 생명과학.pdf (3쪽) 에서 표시한 부분을 찾는 중…
  ✍️  손글씨 읽는 중 2/2
✅ 형광펜 5 · 밑줄 2 · 동그라미 1 · 손글씨 2 · 메모 2
   → 생명과학_요약/요약.html
   → 생명과학_요약/요약.md
```

| 결과물 | 쓰임 |
|---|---|
| `요약.html` | 브라우저로 바로 보기. 색·종류별로 걸러 보기 가능, **인쇄(Ctrl+P) → PDF로 저장**하면 요약본 PDF |
| `요약.md` + `images/` | 노션 · 옵시디언 · 깃허브에 붙여 넣기 |
| `요약.json` | 다른 프로그램에서 쓰기 (`--format json`) |

## 무엇을 찾나

필기 앱마다 PDF에 필기를 저장하는 방식이 달라서, 세 가지를 모두 봅니다.

| 필기 방식 | 예 | 찾는 방법 |
|---|---|---|
| **PDF 주석**으로 저장 | Adobe Acrobat, macOS 미리보기, Xodo, Flexcil, PDF Expert 등 | 형광펜·밑줄·취소선 주석 아래의 글자를 정확히 읽음. 스티커 메모·텍스트 상자·형광펜에 단 댓글도 가져옴. 잉크(펜) 주석은 아래처럼 판정 |
| 필기가 **페이지에 굳어진** PDF | GoodNotes · Notability 등에서 "PDF로 내보내기" | 페이지 속 선 중 손으로 그은 획(반투명 굵은 획 = 형광펜, 둥근 끝 펜 획 = 펜)만 골라냄. 책의 표 선·도형은 건너뜀 |
| 종이책을 **스캔**한 PDF | 스캔 앱, 복합기 | 밝고 채도 높은 색(형광펜)을 찾아 그 부분을 잘라냄. 글자층(OCR)이 있으면 바로 읽고, 없으면 AI가 읽거나 이미지로 넣음 |

펜 획은 모양을 보고 나눕니다.

- **반투명하거나 굵은 획** → 형광펜 (밑에 있는 글자를 읽음)
- **글자 바로 밑의 납작한 선** → 밑줄 (위의 글자를 읽음)
- **글자를 감싸는 고리** → 동그라미 (안의 글자를 읽음)
- **그 밖의 획** → 손글씨 (원본을 잘라서 AI가 읽음. 별표·화살표 같은 기호는 "(별표)"처럼 표시)

그리고 정리할 때

- 줄이 바뀌며 이어 칠한 형광펜은 한 문장으로 합치고,
- 여백에 쓴 손글씨·메모는 **같은 높이(2줄 이내)의 형광펜·밑줄 밑에 붙여서** 무엇에 대한 메모인지 보이게 하고,
- PDF에 목차(책갈피)가 있으면 **단원별로**, 없으면 쪽별로 나눕니다.

## 책에 원래 있던 색칠과 내 형광펜 구분하기

교재 자체에 노란 강조나 빨간 밑줄이 인쇄되어 있으면, 필기본만 봐서는 내가 칠한 것과 헷갈릴 수 있습니다. 방법이 두 가지 있습니다.

### 1. 필기 전 원본 PDF와 비교 (가장 정확)

```bash
pdfsummary 필기본.pdf --original 원본.pdf
```

두 PDF를 쪽마다 겹쳐 보고 **필기본에만 있는 것**만 찾습니다. 책 자체의 색칠·밑줄·그림은 원본에도 똑같이 있으니 저절로 빠집니다.
화면에 보이는 차이를 보기 때문에, 필기 앱이 필기를 주석으로 저장하든 선으로 굳히든 **그림 한 장으로 덮어씌우든** 상관없이 찾습니다.
원본에는 글자층이 있고 필기본에는 없는 경우에도 원본의 글자를 씁니다.

- 쪽 번호가 같은 쪽끼리 비교합니다. 필기 앱에서 쪽을 추가했다면 `--pages`로 범위를 맞추세요.
- 쪽 모양이 크게 다르면(여백 추가 등) 그 쪽은 비교 없이 찾고 안내를 띄웁니다.

### 2. 내 형광펜 색만 인정 (원본이 없을 때)

먼저 이 PDF에서 어떤 형광펜 색이 나왔는지 봅니다.

```bash
pdfsummary 필기본.pdf --list-colors
```

```
색 코드          색        개수  쪽            예시
#F5E563       노랑       42  3,4,7,8,12…   활성화 에너지를
#FFF28C       노랑        9  2,5          기질 특이성
#FF8CBF       분홍       17  3,9,11       경쟁적 저해제
```

예시 글을 보고 내가 칠한 색의 코드를 골라 넣습니다. 같은 노랑이라도 코드가 다르면 구분됩니다.

```bash
pdfsummary 필기본.pdf --color "#F5E563" --color 분홍
```

- 색 코드(`#F5E563`)를 주면 그 색과 거의 같은 것만 받고, 색 이름(`분홍`)을 주면 분홍 계열 전체를 받습니다.
- 펜 색이 PDF에 그대로 들어 있는 경우(주석·선)에는 코드로 정확히 거르고, 종이 위 색만 보이는 경우(스캔·원본 비교)에는 색 이름 계열로 거릅니다.
- 밑줄·동그라미·손글씨는 거르지 않습니다.

## 삼성노트를 쓴다면

삼성노트에서 PDF로 내보낸 파일을 그대로 넣으면 됩니다. 필기가 어떤 형태로 저장되는지는 앱 버전에 따라 다를 수 있어서,
**원본 PDF를 함께 주는 방법(`--original`)을 권장**합니다. 이 방법은 저장 형태와 상관없이 동작합니다.

## 손글씨 처리 방식 (`--handwriting`)

| 값 | 결과 |
|---|---|
| `auto` (기본) | AI가 **확실히 읽은 것은 글로만**, 애매하거나(⚠ 표시와 애매한 부분 안내) 못 읽은 것은 **글 + 원본 이미지** |
| `ai` | 글로만 (AI가 못 읽은 것만 이미지) |
| `image` | AI를 쓰지 않고 원본 이미지 그대로 (`--no-ai`와 같음) |
| `both` | 항상 글 + 원본 이미지 |

AI에게는 손글씨 이미지와 함께 **주변 책 본문**을 같이 보내서, 흘려 쓴 전문 용어를 문맥으로 알아보게 합니다.
같은 이미지는 결과 폴더의 `.ai_cache.json`에 저장해 두므로 다시 실행해도 비용이 또 들지 않습니다.

## 설치

Python 3.10 이상이 필요합니다.

```bash
pip install -e .
```

### AI 설정 (손글씨를 글로 바꾸려면)

[Claude Console](https://platform.claude.com/)에서 API 키를 발급받아 환경 변수로 넣습니다. 키가 없으면 손글씨는 원본 이미지로 들어가고 나머지는 그대로 동작합니다.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_API_KEY="sk-ant-..."
```

기본 모델은 `claude-opus-5-5`이고 `--model`로 바꿀 수 있습니다. 비용은 손글씨 덩어리 하나당 요청 1번입니다.

## 사용 예

```bash
# 기본: 단원별 정리, html + md
pdfsummary 책.pdf

# 색에 의미 붙이기 (형광펜 색을 구분해서 쓰는 경우)
pdfsummary 책.pdf --label 노랑=핵심 --label 분홍=정의 --label 파랑=예시

# 색별로 모아 보기 (예: 정의만 모아서 복습)
pdfsummary 책.pdf --group-by color --label 분홍=정의

# 일부 쪽만, 결과 폴더 지정
pdfsummary 책.pdf --pages 1-40,52 -o 1단원_요약

# AI 없이
pdfsummary 책.pdf --no-ai
```

| 옵션 | 설명 |
|---|---|
| `-o, --out 폴더` | 결과 폴더 (기본 `<파일이름>_요약`) |
| `--pages 1-30,45,50-` | 처리할 쪽 |
| `--original 원본.pdf` | 필기 전 원본과 비교해서 내가 더한 것만 찾기 |
| `--color 색` | 형광펜은 이 색만 (색 이름 또는 `#RRGGBB`, 여러 번/쉼표) |
| `--list-colors` | 찾은 형광펜 색 코드·개수·예시만 보여 주고 끝냄 |
| `--handwriting auto/ai/image/both` | 손글씨 처리 방식 (위 표) |
| `--no-ai` | AI 쓰지 않음 |
| `--model` | 손글씨를 읽을 Claude 모델 |
| `--group-by chapter/page/color` | 단원별(기본) / 쪽별 / 색별 |
| `--label 색=이름` | 색 의미. 색 이름은 노랑·주황·빨강·분홍·보라·파랑·초록 또는 yellow·orange·red·pink·purple·blue·green |
| `--no-attach` | 메모를 형광펜 밑에 붙이지 않고 따로 둠 |
| `--no-drawings` | 페이지에 굳어진 펜 획은 찾지 않음 (책 속 그림이 손글씨로 잘못 잡힐 때) |
| `--scan auto/on/off` | 스캔 이미지에서 형광펜 색 찾기 (기본: 스캔 페이지에서만) |
| `--format html,md,json` | 만들 파일 |
| `--title` | 요약본 제목 |
| `--dpi` | 원본 이미지 해상도 (기본 200) |

## 한계

- **스캔본의 검정 펜 손글씨**는 인쇄 글자와 색이 같아서 찾지 못합니다. 스캔본에서는 색 있는 형광펜만 찾습니다. (원본 PDF가 있으면 `--original`로 찾을 수 있습니다)
- 원본 없이 쓰면, 책 자체의 **반투명한** 색 강조는 내 형광펜과 구분되지 않을 수 있습니다 → `--original` 또는 `--color`.
- 책 자체에 손그림 같은 곡선 그림이 많으면 손글씨로 잘못 잡힐 수 있습니다 → `--no-drawings`.
- 밑줄·동그라미 판정은 모양을 보고 추정하는 것이라 가끔 손글씨로 분류될 수 있습니다 (그래도 원본 이미지가 남습니다).

## 개발

```bash
pip install -e '.[dev]'
python examples/make_sample.py sample.pdf   # 세 가지 필기 방식이 담긴 시험용 PDF
pdfsummary sample.pdf
pytest
```

| 파일 | 하는 일 |
|---|---|
| `pdfsummary/extract.py` | 페이지마다 주석·펜 획·스캔 형광펜을 찾아 표시(Mark) 목록으로 |
| `pdfsummary/strokes.py` | 펜 획 꺼내기, 형광펜/펜 구분, 밑줄·동그라미·손글씨 판정 |
| `pdfsummary/scan.py` | 스캔 페이지에서 형광펜 색 영역 찾기 |
| `pdfsummary/diff.py` | 원본 PDF와 겹쳐 보고 필기본에만 있는 형광펜·펜 자국 찾기 |
| `pdfsummary/pagetext.py` | 영역 안의 인쇄 글자를 글자 단위로 읽기 순서대로 꺼내기 |
| `pdfsummary/ai.py` | Claude로 손글씨·스캔 글자 읽기 (구조화된 출력, 캐시) |
| `pdfsummary/organize.py` | 이어진 형광펜 합치기, 메모 붙이기, 단원/쪽/색별 나누기 |
| `pdfsummary/render.py` | HTML · Markdown · JSON 쓰기 |
